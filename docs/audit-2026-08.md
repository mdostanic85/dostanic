# Portfolio audit — dostanic.net (avgust 2026)

Branch: `portfolio-strategy-improvements`. Build: čist (26 ruta, `next build` prolazi).
Metod: čitanje koda + live dev server + inventar assetа + provera GitHub deploymenta.

---

## Sažetak

Sajt je **vizuelno jak, ali sadržajno tanak**. Dizajn sistem (ICE & INK), tipografija,
motion i struktura su na nivou senior portfolija. Problem je što **case studies nemaju
dokaz** — 8 od 12 ima tačno jednu sliku (cover ponovljen kao "key screen"), a 4 nemaju
nijednu. Sekcija se zove "Evidence, not a gallery" a nema ni evidence ni gallery.

Drugi problem: **template-ovan sadržaj**. AI workflow blok je bajt-identičan na 8 stranica.
Recruiter koji otvori 3 case studyja vidi isti tekst tri puta — to poništava kredibilitet
koji ceo ostatak sajta gradi.

Treći: **6 od 7 tvojih live proizvoda nije na sajtu**. Optronic, Optra, Invoice Tracker su
deployovani i rade. To je najbrža dostupna pobeda.

Prioritet: P0 (bug/kredibilitet) → P1 (sadržaj) → P2 (higijena).

## Playwright plan: automatski screenshotovi iz tvojih deploymenta

Ovo je **najbrža dostupna pobeda**. Provereno stanje tvojih repoa:

| Repo | Live URL | Status | Šta popunjava |
|---|---|---|---|
| `Optronic-v2` | optronic-v2.vercel.app | **200 ✅** | `/work/optronic` — trenutno 0 slika |
| `morning` (WorkLight) | morning-khaki-tau.vercel.app | 404 ❌ | radi lokalno na `:3000` ✅ |
| `client-outreach` (Optra) | optra-ten.vercel.app | **200 ✅** | **nov** Product Builder case study |
| `invoice-limit-tracker-serbia` | invoice-limit-tracker-serbia.vercel.app | **200 ✅** | **nov** case study |
| `Optronic` (v1) | optronic-website.vercel.app | 404 ❌ | — |
| `Nuvio` | — | private, bez deploya | — |

### Zašto Playwright a ne ručno

- deterministički viewport (isti 1600×1000 za sve → konzistentna grid estetika)
- `deviceScaleFactor: 2` za retina
- dark/light varijante iz istog run-a
- ponovljivo: promeniš proizvod → jedna komanda regeneriše sve coverе
- može da uđe u element state (otvoren modal, filter primenjen, tabela sa podacima) što je
  tačno ono što nedostaje — **gusti operativni ekrani, ne landing stranice**

### Skica

```bash
npm i -D playwright && npx playwright install chromium
```

`scripts/capture-screens.mjs`:

```js
import { chromium } from 'playwright'
import { mkdir } from 'node:fs/promises'

const TARGETS = [
  { slug: 'optronic', base: 'https://optronic-v2.vercel.app', shots: [
      { name: 'cover',    path: '/' },
      { name: 'products', path: '/products' },
      { name: 'detail',   path: '/products/<family>' },
      { name: 'de',       path: '/de' },          // EN/DE IA je deo priče
  ]},
  { slug: 'optra', base: 'https://optra-ten.vercel.app', shots: [
      { name: 'cover', path: '/' },
      { name: 'list',  path: '/clients' },
  ]},
  { slug: 'invoice-tracker', base: 'https://invoice-limit-tracker-serbia.vercel.app',
    shots: [{ name: 'cover', path: '/' }, { name: 'forecast', path: '/dashboard' }] },
  // WorkLight ide na localhost:3000 sa ulogovanom sesijom
  { slug: 'worklight', base: 'http://localhost:3000', storageState: '.auth/worklight.json',
    shots: [{ name: 'today', path: '/' }, { name: 'unclear', path: '/unclear' }] },
]

const browser = await chromium.launch()
for (const t of TARGETS) {
  const ctx = await browser.newContext({
    viewport: { width: 1600, height: 1000 },
    deviceScaleFactor: 2,
    colorScheme: 'dark',
    storageState: t.storageState,
  })
  const page = await ctx.newPage()
  await mkdir(`public/work/${t.slug}`, { recursive: true })
  for (const s of t.shots) {
    await page.goto(t.base + s.path, { waitUntil: 'networkidle' })
    await page.addStyleTag({ content: '*{animation:none!important;transition:none!important}' })
    await page.waitForTimeout(600)
    await page.screenshot({ path: `public/work/${t.slug}/${s.name}.png` })
  }
  await ctx.close()
}
await browser.close()
```

Zatim `sharp`/`squoosh` → WebP ≤400 KB, pa `coverImage` + `CaseStudyScreens` unosi u
`src/lib/data.ts` i odgovarajuće `page.tsx`.

### Šta Playwright NE rešava

Screenshot live sajta je **dokaz da stvar postoji**, ne dizajn priča. Za DevRev, Spotify,
OriginChains i koncepte i dalje treba Figma export (flow, token tabela, component varijante,
before/after). Playwright pokriva `optronic`, `worklight` i dva nova projekta — to je 4 od
12, ali su to tačno ona 4 gde je rupa najveća.

### Bonus: dva nova case studyja

`client-outreach` (Optra) i `invoice-limit-tracker-serbia` su **tvoji, javni, deployovani,
sa realnim domenskim problemom** (srpski preduzetnici, NBS kursevi, AI PDF import). To je
direktan dokaz za "Product Builder & AI" tvrdnju koja trenutno stoji samo kao tekst u
Expertise sekciji. Dva case studyja od po 4 screenshot-a vrede više od svih 5 Behance
koncepata zajedno.
