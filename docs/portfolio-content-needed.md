# Portfolio content still needed

The implementation deliberately avoids inventing social proof, metrics, or confidential project details. These inputs are still needed before the portfolio can meet every point in the strategy document.

## Testimonials

Provide two to four approved testimonials. Each one needs:

- Exact quote
- Person's full name
- Role and company
- Permission to publish
- Optional LinkedIn URL and portrait

The strongest quotes should address ownership, complex requirements, engineering collaboration, communication, delivery, or implementation quality.

## Professional photograph

The About page currently uses the public GitHub profile image. Replace it with an approved professional portrait if that image is not suitable for recruiting and client conversations.

## Résumé details

The web résumé and downloadable PDF now use the employment history, education, and language details from the supplied profile. Confirm or provide:

- Any relevant certifications not present in the source profile
- Whether the overlapping TheBrendz, freelance, and studio roles need a more specific explanation
- Approved public client names and the relationship to each client
- Whether location should read Serbia, Belgrade, or Serbia / CET

## Project verification

Review the public classification of every project: client work, internal product, personal product, concept, or capability. Confirm exact role, duration, team, implementation status, and any verified outcomes that can be published.

Space Inch needs an explicit NDA review before adding client names, screenshots, product data, or business results.

## Awards

Do not publish an award count until the number is consistent across the website, résumé, LinkedIn, and Behance.

## External profiles

The website branch cannot update external accounts. LinkedIn, Behance, and GitHub still need the same title, location, dates, contact email, and Product Builder positioning used on the site.

## Analytics

The site now emits provider-neutral `page_view`, `project_view`, `resume_action`, `contact_action`, and `selected_work_action` events. Choose and configure the analytics provider before expecting persisted reports.
